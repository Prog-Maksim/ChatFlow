# ChatFlow - Мессенджер на ASP.NET Core

ChatFlow — это backend-решение для мессенджера, построенное на платформе ASP.NET Core.

> ⚠️ **ПРЕДУПРЕЖДЕНИЕ**
>
> Пожалуйста, имейте в виду, что ChatFlow все еще находится в стадии активной разработки.

## 🛠️ Технологический стек

- **Язык:** C# 13, .NET 9
- **Фреймворк:** ASP.NET Core Web API
- **Аутентификация:** JWT
- **Базы данных:** MySql, Redis, MongoDB
- **Хранение файлов:** S3 хранилище
- **Поиск:** Elasticsearch
- **Контейнеризация:** Docker + Docker Compose
- **CI/CD:** GitLab CI/CD
- **Мониторинг:** Prometheus + Grafana
- **Сбор логов** ElasticSearch + Kibana

## 📡 API

REST API: внешний интерфейс для клиентов (мобильных/веб/Desktop).
WebSocket: для real-time сообщений.

## 🚀 Функционал

На текущий момент в системе реализован следующий функционал:

### 👤 Пользовательский профиль
- Создание и регистрация профиля.
- Авторизация и аутентификация (с поддержкой JWT).
- Поддержка двухфакторной аутентификации (2FA).
- Редактирование профиля (имя, аватар, пароль, номер телефона).
- Получение информации о своём профиле и других пользователях.

### 💬 Сообщения и чаты
- Создание личных (один-на-один) чатов.
- Отправка текстовых сообщений.
- Редактирование отправленных сообщений.
- Получение истории сообщений в чате.
- Удаление сообщений

### 📡 Сетевые коммуникации
- Поддержка WebSocket-соединений для получения сообщений в реальном времени.

### 🔐 Безопасность
- Аутентификация по токенам.
- Поддержка 2FA.
- Разделение прав и валидация доступа на уровне микросервисов.


## 🚀 Будущие планы развития

В будущем планируется добавить следующие функциональные возможности:

### 💬 Расширение функционала сообщений
- Возможность добавлять изображения или видео к сообщениям.
- Реакции (эмодзи, лайки) к сообщениям.
- Статус доставки и прочтения сообщений (delivered / seen).
- Возможность отвечать на конкретные сообщения (reply)
- Поддержка пересылки сообщений между чатами.
- Возможность закреплять сообщения (pinned messages).

### 👥 Расширение функционала чатов
- Возможность создавать группы и публичные/приватные каналы.
- Назначение администраторов и управление ролями в группах.
- Поддержка тем (threaded discussions).
- Архивирование и удаление чатов.

### 🧰 Технические улучшения
- Поддержка многоязычности на уровне API и клиентских данных.
- Повышение отказоустойчивости (Circuit Breaker, Retry Policies).

### 📊 Аналитика и мониторинг
- Статистика по активности пользователей и групп.
- Панель администратора с аналитикой (кол-во сообщений, пользователей и т.д.).

### 🔐 Безопасность и приватность
- Контроль доступа на уровне сообщений (например, самоудаляющиеся сообщения).
- End-to-End шифрование (E2EE) для приватных чатов.
  
### 👤 Личный профиль и настройки
- Настройки приватности (кто может писать, видеть профиль и т.д.).
- Настройка внешнего вида (тема, язык интерфейса).
- Управление блокировками (чёрный список).
- Возможность удаления аккаунта.
